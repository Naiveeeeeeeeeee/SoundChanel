SoundSource 6.1.5

Released on October 5, 2026

  • New “Control Center” Special Source
    On MacOS 27 (Golden Gate) and higher, the new “Control Center” special source captures audio the Mac receives via AirPlay, as well as volume adjustment blips. This replaces the former “AirPlay Receiver” special source due to changes in Golden Gate. More details on special sources can be found in this support article.

  • The ARK plugin which powers SoundSource’s audio handling has been updated to version 13.5.5, bringing substantial reductions in latency, among other improvements.

  • AirPlay reliability has been improved on MacOS 27 (Golden Gate), fixing failed and delayed connections.

  • SoundSource no longer displays phantom AirPlay devices, which could previously appear with certain device groupings. Of particular note, this fixes an issue introduced by tvOS 27, allowing SoundSource to once again correctly identify the names of Apple TVs paired with HomePods or HomePods Mini, rather than identifying them as “Home Theater”.

  • Bluetooth battery levels now correctly display for devices connected after launch.

  • SoundSource now better handles corrupt data files, which could previously result in some devices not appearing as expected in device pickers.

  • Support for IK Multimedia Audio Units has been improved, fixing an issue where these effects would stop responding to mouse events in menus.

  • Generic Audio Unit views now refresh correctly when their parameters list changes.

  • Duplicate capture of an application’s helper processes has been corrected. In rare cases, such as with Microsoft Teams, this could previously result in an inability to mute or otherwise control the parent application.

  • Reverb tails no longer carry over between application audio stopping and restarting.

  • Audio Units on MacOS 27 (Golden Gate) will no longer crash when presenting menus. A crash which could occur when scanning for Audio Units at launch has also been fixed.

  • Mouse drags above the menu bar status item no longer result in SoundSource flickering open and closed.

  • The “Max Volume” slider in the “Devices” window once again correctly updates while dragging. As well, restarting SoundSource is no longer required for volume changes to take effect.

  • Navigating the symbol picker with the keyboard now nicely scrolls, as you should expect.

  • A system popup which could appear when first focusing on a text field appears no longer.

  • Clicks on menu items when SoundSource is not the key window are no longer missed.

SoundSource 6.1.4

Released on September 17, 2026

  • The ARK plugin which powers SoundSource’s audio handling has been updated to version 13.5.4, fixing a crash that could occur with Bluetooth devices not honoring requested buffer sizes on MacOS 27 (Golden Gate).

  • SoundSource will now work as expected with Bluetooth output devices on MacOS 27 (Golden Gate), fixing performance issues caused by a recurrant crash of the underlying ARK plugin.

  • The “System Input” menu bar icon will no longer falsely show a devices as muted if that device in fact cannot be muted (due to lacking a hardware mute feature).

  • SoundSource now always uses software mute when “Force software volume control” is enabled on a device, rather than activating hardware mute if it exists.

  • Audio Unit interfaces now avoid visual clipping when they grow during a resize.

  • Menu bar icons now correctly display in sync across multiple displays.

SoundSource 6.1.3

Released on September 15, 2026

  • The ARK plugin which powers SoundSource’s audio handling has been updated to version 13.5.3. This update contains several improvements, including reduced latency thanks to pipeline improvements and workarounds for dealing with both unreliable Bluetooth devices and devices with unstable clocks.

  • On MacOS 27 (Golden Gate), SoundSource’s window will once again move as expected and the Quick Config menu bar menu will now always respond to clicks as expected.

  • A problem which could occur due to AirPlay device scanning after waking the Mac has been fixed, preventing a rare crash.

  • Effects presets should now correctly match in all cases, fixing an issue with presets imported from SoundSource version 5.

  • Output groups now better handle underlying changes, with their buffer no longer being cleared for configuration changes that don't require a significant latency compensation re-calculation.

  • Several drawing issues have been corrected:

    • Flawed focus rings will no longer draw when presenting an effects context menu.

    • The preset manager sheet is now much faster at displaying a large list of presets.

    • The text displayed when no sources are set as Favorites is now properly aligned within the main window.

    • The preset editor sheet no longer errantly dismisses itself when mouse clicks don't fall inside a control.

  • VoiceOver corrections have been made to fix the order of elements in the “Software Update” section of the “Settings” window to read more logically and ensure checkboxes are correctly viewed as checkboxes.

  • The “Check for test releases” option has been excised from the “Debugging” window, as access to test releases is now available in the “Settings” window.

  • Option-clicking the “Check Now” button in the “Settings” window will once again cause it to check for Developer News.

SoundSource 6.1.2MacOS 27 Support

Released on August 26, 2026

  • Support for MacOS 27 (Golden Gate)
    SoundSource no longer warns on launch when run on MacOS 27 (Golden Gate). There are no known issues on Golden Gate at present.

  • Several AirPlay Enhancements
    Several improvements have been made to SoundSource’s AirPlay streaming:

    • SoundSource now reliably auto-connects to AirPlay devices when sending audio to them.

    • Output Groups and AirPlay devices now correctly re-establish themselves after a restart of coreaudiod.

    • Synchronization between AirPlay devices has been tightened, correcting audible drift that could occur when streaming to multiple outputs for extended periods of time.

    • A “UID already exists” error which could occur when connecting to AirPlay devices has been corrected.

    • The last-used volume for AirPlay devices is now restored upon connecting.

  • Processing of silence has been greatly optimized, so average CPU usage is greatly reduced.

  • SoundSource’s Shortcuts will once again be shown within Apple’s “Shortcuts” app, without requiring a system restart to appear. This fixes a regression introduced in SoundSource 6.1.0.

  • SoundSource now works correctly with the Mixed In Key “SE” Audio Unit plugin.

  • Multiple sources will no longer appear in SoundSource for the same process. This avoids issues where audio could be doubled.

  • When previewing media with Quick Look in the Finder, audio is no longer incorrectly doubled (and thus un-mutable).

  • Improvements have been made to avoid audio from Loopback virtual devices being muted for as long as 10 seconds after the device is no longer being captured by another application.

  • A rare crash that could bring down SoundSource while it was running in the background has been fixed.

  • Interface elements which could appear blurry on non-retina displays should now be crisp.

  • Effect popovers now retain their position when opened via the “Open/Close Effect Window” shortcut.

  • Fresh instances of Audio Unit effects are once again displayed at their initial default size. This fixes a regression introduced in SoundSource 6.1.1.

  • SoundSource will no longer incorrectly appear over the menu bar when “Automatically hide and show the menu bar” is enabled in System Settings.

  • The “Local Network Accession” permission will no longer incorrectly cycle between enabled and denied.

  • SoundSource’s icon has been updated to support the system-wide Dark icon style on MacOS 26 and higher.

  • Easier Access to Test Releases
    It’s now easier to be notified about pre-release versions of SoundSource. In the “Settings” window, you can adjust the new “Check for” menu from its default “Official Releases” option to “Official and Test Releases”. More details on test releases can be found in this support article.

    This setting was previously found in the app’s hidden “Debugging” window. It has now been promoted to the main interface.

Released on July 30, 2026

  • A parameter scaling issue which led presets in the 10-band Lagutin Equalizer to only apply half their intended boost or cut has been corrected. This fixes a regression introduced in SoundSource 6.1.0.

  • Audio devices that lack volume control once again use a pleasing volume curve. This fixes a regression introduced in SoundSource 6.1.0.

  • An issue which could lead to broken buttons and slider interactions when SoundSource was not the focused window has been corrected.

  • Device disconnections will no longer lead to SoundSource overriding the system's chosen default devices. This fixes a regression introduced in SoundSource 6.1.0.

  • Several misspellings and incorrect VoiceOver labels have been fixed throughout the app.

  • Doubled audio will no longer incorrectly be heard when excluding an application that plays multi-channel audio to non-default channels. This fixes a regression introduced in SoundSource 6.1.0.

  • System sleep is no longer incorrectly prevented when “Hey Siri” is enabled.

  • A problem with resource loading that prevented SoundSource from launching on case-sensitive APFS volumes has been fixed. This fixes a regression introduced in SoundSource 6.1.0.

  • AirPlay devices now properly retain previously set volumes in all instances.

  • Initial audio capture and playback to non-default devices has been fixed, preventing a rare problem which could result in silence if audio was playing to a non-default output when SoundSource launched.

  • A rare crash which could occur when reinstalling ARK from the Help menu has been fixed.

  • The legibility of the “Purple”, “Pink”, and “Orange” accent colors has been improved.

  • Assorted window titles throughout the app are now black, rather than an overly muted gray.

SoundSource 6.1.0

Released on July 21, 2026

  • An Optional Quick Config Menu Bar Icon
    Access your quick configs right from the menu bar, by toggling on “Show Quick Configs in Menu Bar” in the “Manage Quick Configs” sheet.

  • Updated Volume Pips in the Menu Bar
    The volume indicator in the application’s menu bar has been updated from sometimes-confusing dots to aesthetically-pleasing bars.

  • Bluetooth Refinements
    Several enhancements have been made for Bluetooth devices.

    • Multiple changes have been made to reduce glitches and dropouts.

    • Device iconography has been updated for several Apple and Beats devices, including AirPods 4 (with ANC), and Beats Pill.

    • Unnecessary drift correction is no longer applied to Bluetooth devices, resulting in fewer glitches.

    • SoundSource now only shows Bluetooth devices that are either already connected, or available to be connected to, rather than all paired devices.

  • Audio Unit Refinements
    Enhancements have been made for Audio Unit effects:

    • When a new Audio Unit is installed, SoundSource will now recognize it immediately, with no need to restart the app.

    • Support for version 3 Audio Units has been improved.

    • Loading a generic view for Audio Units which contain many parameters is now much faster.

    • Compatibility with Audio Units such as “Slate VSX” and “Sound ID” has been improved.

    • A host tempo sync has been added for Audio Units that require it for operation, such as Audiomodern’s “Panflow”.

  • AirPlay Refinements
    Enhancements have been made for AirPlay devices:

    • AirPlay devices re-connect more reliably after waking the Mac from sleep, as well as on launch of SoundSource.

    • SoundSource now automatically reconnects to AirPlay devices when network topology changes, such as those which occur when connecting to a VPN, are detected.

    • AirPlay device audio-visual sync has been improved.

  • “Audio Devices” Window Refinements
    Enhancements have been made to SoundSource’s “Audio Devices” window:

    • A new “Hide All” control is now offered for AirPlay devices. This can be especially useful on large networks with many devices, as it’s now possible to hide all, then unhide only the desired devices.

    • The “Preferred Device Order” control now offers a control for MacOS’s “Sound Effects” device.

    • Hidden devices no longer incorrectly appear in the “Preferred Device Order” lists.

    • When the input level meter is actively reading a device’s input levels, it now correctly causes passively activated meters elsewhere in SoundSource to activate too.

  • Unobtrusive Update Notifications
    SoundSource’s software update notifications have been modified to be less obtrusive, in the hopes of avoiding disruptions. When the timed automated check detects a newer version, it will no longer pop a dialog. Instead, a small “Update Available” indicator will appear in SoundSource’s main window. This change makes it easier for you to control when you update to newer versions.

  • ARK Plugin Updated to 13.5
    The ARK plugin which powers SoundSource’s audio handling has been updated to version 13.5. This big update contains a slew of backend improvements that reduce CPU usage, reduce latency, and increase audio processing integration reducing failure points.

  • Game On With Game Mode
    Thanks to optimizations in underlying audio capture technology, SoundSource now plays nicely with audio playback from games running in MacOS’s “Game Mode”, avoiding crackles or other unwanted artifacts.

  • Crashes Be Gone
    A handful of rare crashes have been snuffed out. A crash will no longer occur when:

    • A device’s channel count changes while switching formats or sample rates.

    • Running Shortcuts intents with incomplete or partially resolved parameters.

    • Audio Unit processing code has been robustified to better handle switching output channel counts.

    • When using keyboard shortcuts with an open menu on MacOS 27 (Golden Gate).

  • SoundSource’s alternate menu (accessed by Control-clicking the SoundSource icon in the menu bar) now includes a “Quick Configs” sub-menu.

  • Dragging and dropping a built-in effect between sources now removes it from the original source and adds it to the destination. Holding option while dragging and dropping will instead copy the effect’s settings. Handy! As well, pasting an effect will now add it to all currently selected sources, the way it ought to.

  • Redirecting audio to a different device is now instantaneous and smooth. As well, changing the system output now avoids volume jumps.

  • It’s once again possible to adjust volume and effect sliders within SoundSource via scrollwheel or trackpad.

  • While SoundSource is in the foreground, type the first few characters of an application’s name to highlight it. This also works with the system devices “Output”, “Input”, and “Sound Effects”).

  • A convenient “Check for Updates” item has been added to the Options (Gear) menu.

  • Issues where Spatial Audio could lead to distortion and audio loss, due to device clock timing variability, have been fixed.

  • Incorrectly doubled audio, which could be occasionally be heard when using AirPods Max connected over USB-C, has been eliminated.

  • Headphone EQ profiles are once again always applied consistently, and do not require re-selection.

  • Virtual audio devices which don’t support being set as a system input, output, or effects device will no longer be included in those menus within SoundSource. They will also not be included in the “Preferred Device Order” lists.

  • Removing a Headphone EQ profile now properly resets applied audio processing.

  • Handling of multi-channel audio formats has been improved.

  • Selecting a second mute timer while one mute timer is already active now works correctly, with the existing mute timer replaced by the new one.

  • It is once again correctly possible to adjust the volume levels for output group devices even before those devices have connected.

  • Fixes for Shortcuts
    Several corrections have been made to Shortcuts:

    • The increment/decrement calculation for the “Set Device Volume” intent has been corrected, to ensure this shortcut works as expected.

    • The “Get Device List” Shortcut intent once again returns input devices.

    • The “Get Source Devices” Shortcut intent no longer returns duplicate devices.

  • Interface Improvements
    A wide array of minor interface improvements and bug fixes have been made, including:

    • When muted, the volume slider thumb no longer incorrectly grays out.

    • The contrast for menu bar meters has been improved.

    • An interface glitch that could cause scroll bars to improperly overlap the “FX” badge has been fixed.

    • An interface glitch that could cause labels in generic Audio Units to be cut off has been fixed.

    • An issue with the initial highlight on the background of channel selection menu items in the “Audio Devices” window has been corrected.

    • Improvements have been made when switching between generic and custom interfaces for Audio Units.

    • The AirPlay section of the “Audio Devices” window is now more accurately titled “AirPlay Outputs”.

    • The “Audio Devices” window has been cleaned up in an assortment of small ways.

    • A visual glitch with the “Add Effect” menu’s filter field has been corrected.

    • The “Audio Device” window now displays a more prominent help message when a Bluetooth device is set to “Output Only”.

    • Audio Units that support custom sizes now feature resize handles.

    • An assortment of visual hover effects have been removed from SoundSource’s interface.

    • Animations throughout the app have been cleaned up.

    • The “Trial Mode” indicator now features a graphical hourglass.

    • A theme color mismatch which could occur in the 10-band Lagutin Equalizer’s popover has been corrected.

    • Tweaks have been made to the hues used for “Accent Colors” in SoundSources. Custom colors are now used as intended, rather than exactly matching MacOS’s colors.

  • VoiceOver Improvements
    Several improvements and fixes have been made when using SoundSource with VoiceOver:

    • The speed of VoiceOver navigation has been improved when moving through large lists.

    • The VoiceOver readout when moving items up and down lists should now always be correct.

    • Items no longer incorrectly lose focus when switching focus between windows.

    • A typo which caused VoiceOver to mispronounce the “Nickname” field in the “Audio Devices” window has been corrected.

  • The “Sound Effects” device now consistently uses a bell icon throughout the app.

  • SoundSource now includes a new “Audio indicators for mic muting” hidden setting. When enabled, muting or unmuting the system’s default input with SoundSource will be accompanied by a brief audio indicator. For full details on hidden settings, see this support article.

  • When redirected, multi-channel audio is now down-mixed prior to effects processing. This enables Audio Unit channel layouts to match the layout of the output device, and reduces CPU usage.

  • SoundSource now displays a warning on any application using “unmixable” audio.

  • Device sorting in the “Output Groups” window has been improved, to re-sort selected devices to the top when the window loses focus. As well, all sorting is now based on alphabetical order.

  • When pinning SoundSource’s main window, the newly-pinned window will now slide away a few pixels to better indicate what has occurred. This is also true of pinning an effect window.

SoundSource 6.0.6

Released on April 16, 2026

  • Enhanced Compatibility with Head Tracking for AirPods and Beats headphones
    Previously, a bug in MacOS could cause quality issues when routing audio to AirPods or Beats headphones. To avoid this problem, SoundSource will now temporarily deactivate head tracking mode when routing audio. For more details, see this support article.

  • Improvements Surrounding Auto-Switching by AirPods and Beats Headphones
    SoundSource’s is now better able to maintain a custom Preferred Device Order (as configured in the “Audio Devices” window) when AirPods or Beats headphones are connected.

  • When using AirPods or Beats headphones with the “Preferred Device Order” settings in the “Audio Devices” window, SoundSource now offers a recommendation to deactivate MacOS’s “Automatic” connection feature, as it can lead to undesired device changes. For more details, see this support article.

  • The ARK plugin which powers SoundSource’s audio handling has been updated to version 13.1.2. This update contains several small improvements, including a fix for issues which could incorrectly prevent system sleep.

  • Several improvements have been made to SoundSource’s volume overlay:

    • The overlay is now centered on the display when shown over a full-screen app, rather than in the top-right corner.

    • The overlay now features a close button, allowing it to be dismissed instantly.

    • The contrast of the overlay has been improved, for better visibility against light backgrounds.

    • An issue where the overlay would not consistently appear when adjusting volume via keyboard, or could disappear prematurely, has been corrected.

  • Sharing audio on a Zoom call should now always work as expected.

  • Previously, adding SoundSource as a login item could fail if stale login items existed for other copies of SoundSource. No longer!

  • Audio synchronization between devices in an output group has been improved.

  • A bug where creating a new Quick Config could inadvertently cause adjustments to current settings has been squashed.

  • A rare issue where SoundSource could fail to fully launch, leaving a blank space in the menu bar, has been resolved. This same fix avoids an issue which sometimes led to elevated CPU usage.

  • A clock tracking issue which could lead to silent playback or audible distortion when playing to Bluetooth hardware has been corrected.

  • An assortment of interface improvements and bug fixes have been made:

    • Work has been done to prevent SoundSource’s main window from incorrectly drawing with a dimmed appearance.

    • When SoundSource is launched, its icon now appears in the menu bar much faster.

    • Checkboxes in the “Audio Devices” window will now have correct contrast when the window is in the background.

    • Battery level display for Bluetooth devices now more accurately reflects reported levels below 20%.

    • An issue where opening secondary windows with keyboard shortcuts could later cause incorrect behavior by the main window has been fixed.

    • Clicking the dismiss (X) button on high priority notifications will no longer cause SoundSource to incorrectly activate its windows.

    • The symbol picker’s search field now properly accepts keyboard input when opened.

    • Naming a preset no longer incorrectly fails when the hosted Audio Unit has an active text field.

    • Devices will no longer move up or down in the list when added or removed from a group in the “Output Groups” window.

    • Several minor drawing issues which could occur when opening effects have been corrected.

    • When navigating the Effects menu with the keyboard, the search field now correctly re-gains focus when it's the next selectable item based on the direction of navigation.

    • Interacting with the generic view of some Audio Units, including those from Airwindows, could cause a hang. This issue has been corrected.

  • A crash when switching tabs in the Settings window on MacOS 15 has been resolved.

  • With enough effort, locked device settings could be lost via persistent external modifications to that setting. That issue has been addressed, and locked settings should stay locked even in that unusual situation.

SoundSource 6.0.5

Released on March 18, 2026

  • ARK Plugin Updated to 13.1
    The ARK plugin which powers SoundSource’s audio handling has been updated to version 13.1. This update contains several changes, including an improvement that will prevent the need to enter your administrator password for future updates.

  • When the relevant “Preferred Device Order” option is enabled in the “Audio Devices” window, SoundSource will now adjust the system output and/or system input when it launches, in addition to when devices appear or disappear.

  • Several improvements have been made to AirPlay streaming:

    • If a Quick Config includes an AirPlay device configured as the system’s default output, loading it will now always correctly update, as expected.

    • AirPlay devices no longer incorrectly remain cached and visible in SoundSource when switching wireless networks.

    • When AirPlay and regular devices are used together in an output group, initial sync is now improved.

    • If a selected AirPlay device disappears, then reappears, its selection will now be restored.

  • Bluetooth devices are now only shown as reachable when they are actually visible, reducing stale or incorrect availability states.

  • Auto-connection and error reporting should now behave correctly when AirPods are part of a device group.

  • Mouse clicks are no longer incorrectly blocked for the preset manager sheet used by Audio Unit plugins.

  • Custom keyboard shortcuts are now correctly cleared when selecting “Reset to Defaults” for an application or system device.

  • Rendering the interfaces for Waves plugins on mixed DPI displays now works as expected, and compatibility with FabFilter's Pro-Q solo mode has been improved.

  • Missing Audio Units are now handled more gracefully, avoiding failures when loading some plugins.

  • Several VoiceOver improvements have been made, including:

    • Multiple corrections have been made for audio effects, including fixes for focus getting trapped on non-visible elements.

    • The “Release Notes” window now appears immediately when selected, as it should.

    • Sub-menus will no longer occasionally appear empty.

  • A few interface inconsistencies have been corrected:

    • Plugin popovers now open at their correct size and position immediately, eliminating an intermediate resize that previously caused a visible jump when reopening a plugin.

    • When muting the input device, the microphone no longer jumps to the side visually.

    • Virtual device name changes are now reflected in SoundSource immediately.

    • Popovers will always appear on a visible display when opening SoundSource from the menu bar.

    • SoundSource now avoids shrink animations when MacOS’s “Reduce Motion” option is enabled.

    • The “Sound Effects” options section no longer contains an erroneous (and always unavailable) “Show system effects in menu bar” setting.

    • An issue where SoundSource’s main window could sometimes incorrectly appear inactive has been fixed.
